# Logos de consoles (sources)

Ces logos monochromes proviennent de **Monochrome (Retro) Gaming Logos** par HVR88 :
https://github.com/HVR88/Monochrome-Gaming-Logos

Selon le README de ce dépôt : usage libre avec mention et lien vers le dépôt ; certaines images sont
couvertes par des droits de tiers et beaucoup sont des marques de leurs propriétaires (reproduction
artistique pour identification, sans affiliation ni cautionnement), avec d'éventuelles restrictions en
usage commercial. Le dépôt ne porte pas de licence formelle.

**ES-NE est un projet non commercial.** Si un système n'a pas de fichier ici, le thème utilise un logo
typographique original (voir `tools/theme/gen_assets.py`).
